# mkelvers.tech

My personal portfolio, built with SvelteKit and Tailwind CSS.

[Visit mkelvers.tech](https://mkelvers.tech)

## Develop

```sh
bun install
bun run dev
```

Run `bun run check` to check types and `bun run format:check` to check formatting.

## Deploy

```sh
bun run build
bun run start
```
